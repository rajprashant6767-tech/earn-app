ZyloBet Telegram membership backend (multi-channel)

Deploy these files to your existing Render web service. Keep TELEGRAM_BOT_TOKEN set. TELEGRAM_CHAT_ID can remain set for backward compatibility. TELEGRAM_CHANNEL_LINK is optional.

For every channel added in the app, the same bot must be an administrator and have access to member information. The app verifies each listed public channel separately; users must join all listed channels.
